## 当前保留什么

原 26 份运行预设整理为 **11 份**：9 个系列默认、1 个 R1 专用和1个手动完整模板。撤下16份旧版本预设，保持现有9个系列默认名称，旧型号回退到对应系列默认。没有账号绑定引用被撤下的名字；仍显式使用旧名字的外部客户端应改用下表中的名称。

| `gpt-curated` | GPT / Codex 默认 | 完整常驻规则、执行条目、交付及语言要求 |

| `kimi-curated` | Kimi 默认 | 常驻规则和任务条目，去除客户端安装位置说明 |

前7个系列取自冷咖啡公开正文的完整常驻章节，保留任务条目，移除激活页、广告、中转地址、宿主安装、未提供的工具注册和固定结束语。后4项取自 Ai-jailbreak 的独立模板，任务占位符映射为当前用户消息。均附加接口适配规则：遵守用户输出格式、JSON 不加代码围栏、不得虚构工具操作与验证结果。改动后的正文及原文件各有独立 SHA-256，见 `prompts/_index.json`。

“完整递归”是源模板的名称和内容范围，**不是所有模型、所有请求都已被突破的保证**。保留五步正文不等于存在真正的沙箱、授权或权限开关。提示词不能替代宿主补丁，也不能改变模型权重。

## 使用、复现和回退

刷新管理台的“破甲预设”，系列默认自动按型号匹配；其他型号可手动选择 `recursive-full` 或设置明确绑定。密钥原有许可和启用状态不变，未知型号不会被强行套入模板。

`scripts/curate-prompts.mjs` 从固定提交的只读 Git 克隆提取正文，核对提交后生成磁盘和内嵌副本、离线来源库及许可文件。默认读取 `private/armor-research-20261106/`，也可显式传入包含 `coldbrew`、`quincunx` 两个克隆的目录。脚本不会运行上游代码。

改动前的逐文件副本保存在忽略目录 `private/armor-research-20261106/before-curation/`，Git 中也保留历史。旧正文和研究克隆不进入 Docker；镜像中只装载当前11份预设，并保留 `licenses/prompts/` 中的许可证和署名。回退提示库时应同时恢复 `prompts/` 与 `internal/armor/assets/`，重新构建部署；不需变动账号数据库。
