# 华为果办与码道接入

2026-11-06 修复了码道合法回调被误报“状态不匹配”的问题：华为回调中的 `state` 并非本地传入的 `ticket_id`，不能直接比较。授权码通过本次登录会话的 PKCE verifier 兑换；更新容器后需要重新发起授权，不能复用旧会话的回调地址。

本轮接入的正式产品是**果办 OfficeAce**与**华为云码道 CodeArts**，方向是把这两个产品自身的模型服务接入 relaypool 账号池，不是给它们配置第三方模型。不是 DevEco Code 或 DevEco CLI，也不把华为云 MaaS API Key 当作这两个产品的登录态。

## 当前能力与验证范围

| 能力 | 码道 CodeArts | 果办 OfficeAce |
| --- | --- | --- |
| 管理台渠道 | 独立渠道 `codearts` | 独立渠道 `officeace` |
| 浏览器授权 | 本机回调地址手动回填，支持门户两阶段跳转 | 华为云页面登录，服务端轮询取码 |
| 手动导入 | 临时 AK/SK、安全令牌及到期时间；或显式永久 AK/SK | 应用 Key、应用 Secret、账号下发的模型网关地址 |
| 目录 | 查询当前账号内置目录；可手填型号 | 查询当前账号网关目录；可手填型号 |
| 三种客户端入口 | Chat Completions、Responses、Messages | Chat Completions、Responses、Messages |
| 回复形式 | 流式、非流式聚合、函数工具和思考内容传递 | 流式、非流式聚合、函数工具和思考内容传递 |
| 自动续期 | 有完整刷新材料时刷新临时 STS，永久 AK/SK 不刷新 | 后台保活续期积分所需 STS；聊天仍使用独立应用密钥 |
| 积分查询 | 查询账号总积分、已用和剩余积分 | 汇总有效套餐与奖励积分，排除过期和未生效权益 |
| 签到 | 查询每日登录活动资格、领取并复核状态 | 领取奖励并对比领取前后的奖励余额 |

这些是适配代码的能力。自动测试使用合成凭证与本地模拟服务，验证签名、权益解析、领取复核与错误处理。真实账号的领取资格和可用型号仍由华为决定。工具、图片和具体思考参数是否被接受，取决于上游实际型号；模型目录不是逐型号推理成功证明。

## 积分查询和每日签到

在“账号池”刷新额度，或进入账号详情查看剩余、已用和总积分；点击“领取每日积分”手动签到。开启该账号的“每日自动领取”后，按管理台显示的后台计划执行，以北京时间自然日去重。查询余额本身不领取奖励、不续期令牌，也不改变账号启停状态。手动领取后清除旧余额缓存，界面重新读取余额。

- **码道**：通过统计接口读取 `usageTotalPackageCredit`，只领取上游允许的 `USER_LOGIN` 每日登录奖励；不领取邀请或学生认证活动。使用每日稳定请求标识防止重复领取，之后重新查询活动状态。
- **果办**：通过账号官方网关的订阅接口查询权益，用独立的 V11 签名读取有效套餐和奖励。领取后重新查询奖励余额，只有核实新增奖励才显示成功；没有新增时说明已领取或无资格，不把 HTTP 200 当成到账。
- 奖励数额和有效期由上游活动决定，不硬编码固定赠送积分。过期、未生效权益不计入果办可用余额；缺失字段、无有效权益、查询失败显示未知或失败，不伪造零余额。
- 果办仅导入应用 Key/Secret 可以调用模型，但不能查询积分或签到。请使用浏览器重新授权取得完整的临时 AK/SK、安全令牌及到期时间。积分 STS 与聊天应用密钥独立，积分权限过期不会直接停止聊天。
- 有完整刷新材料时，后台保活及签到前会续期即将过期的登录态，并先保存续期结果；果办保留独立应用密钥和模型设置。纯积分查询不会轮换令牌，提示到期时可点击领取触发续期；刷新失败或授权不完整时需要重新授权。只向官方果办网关发送积分签名，不向自定义第三方模型地址发送 STS。

接口协议来自已注明的公开实现与官方客户端行为，可能随版本变化。活动规则参见[码道福利说明](https://support.huaweicloud.com/offers-codeartsagent/codeartsagent_offers_0004.html)和[果办积分说明](https://support.huaweicloud.com/qs-officeace/officeace_01_0003.html)。

### 2026-11-06 本机验收

已在更新后的 Docker 容器中使用现有两个授权账号实测：码道每日奖励新增 100 积分，余额由 4499.96 变为 4599.96；果办先遇到控制面 STS 过期，签到前自动续期并持久保存后成功领取 100 积分，查询余额约 4599.9969。再次手动领取时，两边均确认当日已领取，余额没有重复增加。这些数值仅为当次记录，不代表所有账号的套餐或固定奖励额度。

全量 Go 测试、静态检查通过；后续签到续期修改通过调度器、华为适配器及 API 回归，并通过调度器与华为适配器竞态检查。没有用模型聊天消耗积分做签到验收。

## 浏览器授权

在本机管理台选择“账号池 → 浏览器登录”，选择对应华为渠道与中国站。账号名称和可用型号可按需填写；没有明确型号时留空，登录后在详情查询目录。

### 果办 OfficeAce

1. 开始授权，打开返回的华为云登录页。
2. 在自己的浏览器登录并同意授权，返回管理台等待轮询。
3. 成功后登录态加密保存并启用账号。打开详情查询上游型号。
4. 如果提示账号尚未获得模型服务，需要先在官方客户端完成产品开通。登录授权不自动购买套餐、兑换邀请码或领取活动奖励。

服务端从固定果办控制面获取云端状态，再用 PKCE 和 DPoP 换取自己的临时凭证，并查询自己的应用密钥。不会把果办令牌拿去登录码道。可使用不同浏览器配置或隐私窗口选择其他账号；本实现不会主动登出你已有的华为云浏览器会话。

### 码道 CodeArts

1. 开始授权并打开码道门户。
2. 当浏览器跳到无法连接的 `http://127.0.0.1:12800/oauth/callback?...` 页面时，复制地址栏完整内容，粘贴回管理台的授权回填框。
3. 如果该地址包含 `secret` 与 `redirect`，提交后点击管理台更新后的授权链接继续登录。
4. 再次跳到本机地址且包含 `code` 时，回填完整地址并提交；随后等待保存完成。

这是手动回填流程，Docker 无需额外开放 12800 端口。该端口仅用于门户回调约定，浏览器显示无法连接在此流程中是预期情况。不要把完整地址、授权码、刷新材料发到聊天或公开 Issue。

## 手动导入

选择“添加账号”，渠道选果办或码道，凭证类型选登录态；把自己合法导出的 JSON 粘贴或上传。项目不会自动扫描客户端文件或读取系统钥匙串。

### 码道临时凭证

```json
{
  "access_key": "REPLACE_WITH_OWN_TEMPORARY_AK",
  "secret_key": "REPLACE_WITH_OWN_TEMPORARY_SK",
  "security_token": "REPLACE_WITH_OWN_SECURITY_TOKEN",
  "expires_at": "2099-01-01T00:00:00Z",
  "models": ["REPLACE_WITH_ACTUAL_MODEL_ID"]
}
```

上面的日期只是格式占位，必须替换为真实到期时间，不能通过修改时间延长上游权限。缺少刷新材料时到期后需要重新授权／导入。完整可续期登录态还包括 `refresh_token`、`dpop_private_jwk` 和 `code_verifier`；这些值必须来自同一次授权，不能随意拼接。

永久 IAM AK/SK 需要显式声明，且实际可用性仍由上游账号授权决定：

```json
{
  "credential_kind": "aksk",
  "access_key": "REPLACE_WITH_OWN_IAM_AK",
  "secret_key": "REPLACE_WITH_OWN_IAM_SK"
}
```

永久凭证不应带临时 `security_token`。不要为接入本项目而扩大 IAM 权限；没有可用 IAM 凭证时使用浏览器授权。

### 果办应用凭证

```json
{
  "model_app_key": "REPLACE_WITH_OWN_APP_KEY",
  "model_app_secret": "REPLACE_WITH_OWN_APP_SECRET",
  "model_base_url": "https://REPLACE-WITH-ACCOUNT-GATEWAY.example/v2"
}
```

网关地址必须用账号实际下发的 HTTPS 地址，不能把示例域名直接用于真实调用。只导入果办控制面的临时 AK/SK 不足以聊天。应用密钥不按 STS 的到期时间过期，但仍可能被上游撤销或因账号权益变化而失效。

两种渠道都允许 `models` 字符串数组；填写后以手动列表作为目录，不再请求自动目录。未填写时自动查询；不硬编码一份所有账号都可用的固定型号清单。

## 调用与排错

先为调用密钥授权对应账号和具体型号，再按 [API 文档](API.md)查询 `/v1/models`。多渠道场景可用 `codearts/实际型号` 或 `officeace/实际型号` 固定渠道，权限仍由白名单控制。

| 现象 | 处理 |
| --- | --- |
| 码道临时凭证过期 | 使用浏览器重新授权；只有完整刷新材料才能自动续期 |
| 果办提示未开通 | 先到官方客户端确认产品开通与账号权益 |
| `ModelArts.81004`／`81009` | 当前账号无该型号权限或型号不存在，按模型故障处理，不直接隔离整个账号 |
| `81111`／`81114` | 模型限流，按限流冷却处理 |
| `81113`／`81001` | 正文或参数无效，不无限换号重试 |
| `APIG.1009`／`APIG.0303` | 检查果办应用密钥、网关和账号权益；不能单凭错误认定积分为零 |
| HTTP 200 但流中报错 | 本适配器识别首帧及中途错误，回复不会被当作正常完成 |
| 积分为未知 | 查看详情提示，确认完整浏览器授权和有效套餐；缺失权益不等于零积分 |
| 签到后没有新增积分 | 可能今天已领取、当前无资格或上游尚未确认到账，稍后查询；不代表请求必然失败 |

先用一条短消息验证，避免批量逐型号探活消耗积分。函数工具调用只传递工具定义和调用结果，不会把用户电脑上的果办 Skills、文件或桌面操作能力自动搬到 Docker 网关。
