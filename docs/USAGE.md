# 使用说明

## 登录与页面

打开 `/console/`，使用网关管理密钥进入工作台。管理密钥通过本机命令 `docker exec relaypool /app/relaypool -show-api-key` 读取；上游账号的 API Key 或 OAuth Token 不能用于登录管理台。

| 页面 | 用途 |
| --- | --- |
| 概览 | 账号状态、请求成功率、Token、耗时和近期请求 |
| 账号池／账号详情 | 添加、导入、授权、启停、额度与目录查询、测试及调度参数 |
| 聊天 | 选择型号／账号、多会话、流式回复、停止、重试和复制 |
| API 密钥 | 创建、撤销密钥，设置管理／调用范围及白名单 |
| 破甲预设 | 管理提示词预设、模型绑定、导入导出及匹配预览 |
| 请求日志 | 查看请求、错误、实际账号和每次换号尝试 |
| 连接设置 | 当前浏览器的后端地址与管理密钥 |

“连接设置”不会修改服务端监听地址。自用版没有用户注册、用户平台、计费或网络配置页面。

## 添加账号

推荐先接入一个账号并完成短消息验证，再扩大号池。

1. 进入“账号池”，选择浏览器登录、添加 API 账号或导入凭证。
2. 确认平台、地区、基础地址和凭证类型一致。
3. 浏览器授权按页面跳转，在自己的浏览器完成登录。需要手动回填时，粘贴完整回调地址或完整授权码，不要丢弃状态字段。
4. API 账号填写自己的上游密钥；导入登录态则提供该渠道要求的完整字段，导入失败会显示缺失原因。
5. 查询模型目录；渠道要求手填型号时，填写上游账号实际有权使用的精确 ID。
6. 启用账号，在“聊天”页指定这个账号和型号进行验证。

账号测试和聊天会向真实上游发送请求，可能消耗额度。目录查询成功不等于模型推理权限全部可用。

## 渠道支持范围

以下描述来自当前适配代码，不是对平台未来协议或账号权益的承诺。

| 渠道 | 主要接入方式 | 注意事项 |
| --- | --- | --- |
| WorkBuddy | 国内／国际浏览器授权或完整登录态 | 支持目录、额度及每日签到，具体结果取决于上游 |
| Qoder | 浏览器授权、完整账号 JSON 或 personal token | 国内／国际地区需匹配；直接调用协议，无需额外运行 Qoder CLI；不直接导入 CLI 加密凭证 |
| Trae 国内 | 浏览器授权或完整登录态 | 保留原 `uid`、`machine_id`、`device_id` 等字段；支持资格查询后的积分领取 |
| Trae 国际 | 浏览器授权或完整登录态 | 远程会话文本回复；不自动创建项目；当前不支持客户端函数工具、图片、采样或思考控制 |
| Claude | 官方 API 密钥、浏览器授权或 Claude Code 登录态 | 支持回调／授权码回填；上游模型权限单独决定 |
| Gemini | 官方 API 密钥或 Code Assist 登录态 | Code Assist 需要项目 ID，自动续期需要对应 OAuth 客户端配置 |
| OpenAI | 官方 API 密钥 | 使用原生 Responses 上游；ChatGPT 订阅登录态应选择 Codex |
| Codex | 浏览器授权或自己的 Codex 登录态 | 填写实际可用模型；不等于 ChatGPT 网页会话接口 |
| DeepSeek、Grok、Qwen、GLM、Kimi、豆包、混元、MiMo | 对应平台官方 API | 地区、地址、套餐和密钥配套；网页登录态不自动等于 API 凭证 |
| OpenAI 兼容服务 | 自定义基础地址和 API 密钥 | 地址需要包含服务要求的接口前缀；兼容程度取决于上游 |

GLM、豆包、MiMo 等渠道可能要求手填实际模型 ID。不要用品牌名代替模型 ID。Code Assist、Codex 等目录也可能需要手动配置；页面展示的能力和错误提示比静态清单更具体。

## 账号池如何工作

请求先按密钥权限、模型和渠道筛选账号，再考虑启用状态、冷却、额度组和并发容量。支持三种路由策略：

| 值 | 含义 |
| --- | --- |
| `round-robin` | 在符合条件的候选中轮换 |
| `weighted-round-robin` | 按权重进行平滑轮换 |
| `fill-first` | 优先使用当前排序中可承接请求的账号 |

优先级、会话绑定、地区和额度到期偏好会影响候选选择，不能只凭权重推断所有请求的分配比例。单账号并发上限与单请求最大尝试账号数分别配置。

失败会按类型决定是否换号，以及冷却整个账号、当前型号或共享额度组。流式回复已经开始发给客户端后，不会把另一账号的回答拼接进当前流。请求日志可以查看实际尝试链路。

## 管理密钥和调用密钥

管理密钥可以操作 `/admin/*`。调用密钥用于 `/v1/*`，不能管理账号、读取后台或修改其他密钥。

建议为每个本机客户端创建独立调用密钥，设置账号与模型白名单。勾选“允许全部”表示不限对应范围；关闭“允许全部”后留下空白名单表示禁止调用。模型规则按具体型号匹配，不支持用通配符放行。

完整密钥在创建时展示，请及时保存。列表不会再次提供完整明文。修改名称只改变名称；预设使用许可、实际开关与账号／模型权限是独立设置。最后一个有效管理密钥不能删除或降权。

## 聊天与提示词预设

聊天页支持会话搜索、重命名、独立草稿、停止、失败重试和历史恢复。历史与草稿保存在当前浏览器的本地存储中，并按后端地址区分；清理浏览器数据、更换浏览器或更换后端地址后，可能不再看到原会话。Docker 数据卷不包含这些浏览器历史。

预设需要同时满足密钥已获准使用、实际开启及型号匹配。候选预设和实际生效状态是两回事。聊天诊断和响应头可以帮助核对匹配结果；普通任务完成不证明模型限制被改变，也不保证回复质量。

账号上的系统提示词清理选项会影响未应用预设时的上游请求。需要保留客户端自己的系统指令时，检查对应账号配置，不要只检查聊天文本。

## 签到、额度和统计

自动签到按平台能力执行：WorkBuddy 每日签到、Qoder 活动奖励、Trae 国内每日积分，Trae 国际及多数官方 API 没有已接入的签到接口。账号开关与全局调度开关都可能影响是否执行。Qoder 活动按北京时间 10 点开始的窗口去重，实际可领取资格以上游为准。

未返回的额度和 Token 显示未知，不补成零。统计来自当前保存的请求日志，并非上游完整账单；默认日志保留 7 天。这里的剩余额度、Credits 和统计费用字段不代表本地收费，自用版没有钱包或支付结算。
