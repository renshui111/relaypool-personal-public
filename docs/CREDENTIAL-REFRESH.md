# 登录态续期与并发修改保护

## 修复的问题

后台保活、签到前续期可能与用户重新授权、导入新凭证或删除凭证同时发生。上游请求开始后，本地凭证可能已经变化；迟到的刷新结果不能覆盖这些修改。

旧保存逻辑只有在适配器返回 `PreviousRaw` 时才执行比较更新；缺少该字段时直接写入。当前 WorkBuddy 续期没有返回此字段，因此会走直接写入路径。受控回归复现了三种问题：旧续期覆盖用户新凭证、已删除的凭证被重新插入、续期清空昵称／域名／企业等展示信息。

## 现在如何处理

1. 调度器在调用上游前复制原始凭证，保留独立快照；即使适配器复用输入缓冲区，也不会改变用于核对的旧值。
2. 上游成功后，用快照与数据库中的当前凭证在同一事务内比较。仍相同才保存新令牌和有效期；写入仍沿用现有加密存储。
3. 当前凭证已改变或已删除时，不写入旧结果、不重新创建凭证，也不触发“续期成功”的账号健康重置。
4. 缺少原始凭证时不发起此次续期；保存端缺少快照或续期结果为空时明确返回错误，不回退到直接覆盖。
5. 正常续期保留现有昵称、域名、企业展示字段。签到前续期完成后重新读取实际持久化的凭证：用户替换过凭证时使用新值；凭证已删除时停止领取。

以上机制覆盖调度器的后台保活与签到前续期。请求路径的补充校验见下一节。这些更新不改变登录协议、访问权限、签到资格或任务时间。没有数据库迁移或新增配置，更新镜像即可生效；无需为了应用修复重新登录。

## 请求触发续期与回读

2026-11-09 后续更新统一了请求读取器的三条返回路径：首次解码、成功续期、条件更新未写入后读取用户的新凭证。旧实现只在首次读取时完整补齐身份并校验地区，后两条路径依赖适配器返回全部字段，可能丢失账号归属或原始数据，也没有相同的冲突检查。

- 账号 ID 和渠道以本次读取的数据库记录为准，原始凭证保留完整内容，适配器可以省略这些归属字段。
- 适配器若明确返回与账号不一致的渠道或地区，则拒绝使用，不把冲突值静默改成账号设置。
- 续期结果为空时在写库前拒绝；请求发起续期前复制独立旧快照，防止输入缓冲区被复用后比较错值。
- 并发替换导致条件更新未写入时，重新读取当前凭证并执行相同校验。若此时账号渠道／地区与开始读取时不同，返回“账号渠道或地区已变化，请重新发起请求”，不继续用原适配器解释新渠道的数据。
- 一次读取最多尝试一次续期，不因并发替换再递归刷新；健康状态仍只在实际写入成功后重置。

这是请求读取边界的检查，不是覆盖整个推理过程的账号配置锁，也没有新增修改账号渠道的界面。上游各平台是否需要按请求续期，仍由原有策略决定；本轮不为 WorkBuddy 强制增加每次聊天续期。

## 边界与排查

保护的是本地保存顺序，不是将所有上游刷新请求合并为一次，也不能撤销已经发送到上游的令牌轮换。平台端若已使凭证失效，仍需按账号状态重新授权。

比较依据是原始凭证内容，而非独立修订号；如果删除后重新导入完全相同的原始内容，比较会认为内容未改变。本轮未加入凭证修订号。只有成功保存才重置健康状态；并发编辑被保留不应被解释为上游续期成功入库。

查看 `docker compose logs --since 30m --tail 200 relaypool` 中的 `persist refreshed credential` 和 `keepalive` 信息。若看到“缺少原始凭证快照”或“续期结果为空”，此次写回已被拒绝，应检查适配器及账号凭证，不要通过删除数据卷重试。排查时不公开授权回调、令牌或数据库。

## 受控验证

使用临时 SQLite 数据库和测试凭证，不接触生产账号：

| 场景 | 预期结果 |
| --- | --- |
| 原凭证未变，适配器未提供快照 | 新令牌正常保存，健康重置一次，展示字段保留 |
| 上游续期未完成时导入新凭证 | 用户的新值保留，旧结果不触发健康重置 |
| 上游续期未完成时删除凭证 | 凭证保持删除，不重新插入；签到不继续 |
| 适配器原地修改输入缓冲区 | 仍用调用前的独立快照核对，正常保存 |
| 缺少原始凭证／保存快照／刷新结果 | 拒绝不完整操作，已有凭证不变 |

前四项分别覆盖保活和签到前续期；恢复旧调用与直接保存逻辑后，回归明确失败，修复后通过。`go test ./...`、`go vet ./...`、调度器和存储层的竞态检查、API 竞态检查均通过。真实上游调用只验证兼容性，不通过删除或替换生产凭证来测试并发场景。

请求读取器另有 12 个场景：成功续期、输入缓冲区复用、空结果、续期渠道／地区冲突、并发替换后补齐字段、替换凭证的渠道／地区冲突、回读发现账号渠道／地区变化、删除凭证及首次读取渠道冲突。使用旧读取器时回归失败，修复后通过；原有 Claude、Qoder、Trae 的刷新替换回归一并通过。渠道变化使用测试数据库模拟，不代表管理台开放了运行时改渠道入口。
